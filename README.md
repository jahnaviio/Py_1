# Student Performance Analyzer

A beginner-friendly Python project that analyzes student academic performance based on marks entered by the user.

## Features

* Accepts student details
* Stores marks using Python lists
* Calculates:

  * Total Marks
  * Average Marks
  * Percentage
  * Highest Mark
  * Lowest Mark
* Assigns grades automatically
* Displays Pass/Fail status
* Identifies subjects needing improvement
* Provides performance feedback
* Demonstrates list slicing for marks analysis

## Technologies Used

* Python
* Lists
* Loops
* Conditional Statements
* User Input Handling
